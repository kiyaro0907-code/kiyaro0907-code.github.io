プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-15

1. アクセスするGoogleユーザーデータ / Google user data accessed

本アプリは、Googleドライブの全ファイルへのアクセス権限（スコープ: https://www.googleapis.com/auth/drive、表示名「Google ドライブのすべてのファイルの表示、編集、作成、削除」）を要求します。この権限は、運営者自身のGoogleドライブにある既存の指定フォルダへ動画を保存するために必要です（アプリが作成したファイルのみに限定される権限では、既存フォルダへ保存できないため）。実際の利用は、指定フォルダとそのサブフォルダの確認・作成と、動画ファイルのアップロードに限ります。それ以外のファイルの閲覧・変更・削除は行わず、Gmail・連絡先など他のGoogleデータにはアクセスしません。

The app requests full Google Drive access (scope: https://www.googleapis.com/auth/drive, "See, edit, create, and delete all of your Google Drive files"). This is needed to save videos into a designated existing folder in the operator's own Google Drive, which the narrower app-created-files-only scope cannot do. Actual use is limited to checking or creating the designated folder and its subfolders and uploading video files. The app does not read, modify, or delete other files, and does not access other Google data such as Gmail or Contacts.

2. 利用目的 / Purpose

Discordチャンネルに投稿された動画を運営者自身のGoogleドライブに保存するためだけに利用します。

Data is used solely to save videos posted in the operator's Discord channel to the operator's own Google Drive.

3. 保存・共有 / Storage and sharing

運営者のサーバーには、OAuthトークンと、保存処理の記録（処理状況・保存先ファイル名など）のみを保存します。動画ファイルは保存処理のため一時的にサーバーへ置き、処理後に削除します。Googleユーザーデータの販売、共有、第三者への提供・転送は一切行いません。

The operator's server stores only OAuth tokens and processing records (such as job status and saved file names). Video files are kept on the server only temporarily during processing and deleted afterward. Google user data is never sold, shared, or transferred to any third party.

4. Limited Use

本アプリによるGoogle APIから受け取った情報の使用および他アプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに準拠します。

The app's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. アクセスの取り消し / Revoking access

いつでも https://myaccount.google.com/permissions から本アプリのアクセス権を取り消せます。

You can revoke access at any time at https://myaccount.google.com/permissions.
